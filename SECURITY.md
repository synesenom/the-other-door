# Security

*The other door* runs on your own computer: there is no server, account or service of the project's
that holds your data. A security problem is still worth reporting, for example:

- a way for a job ad, a web page or a CV file to make *The other door* run a command, read or write a
  file outside its data folder, or send your data somewhere;
- the phone app's pairing or its server answering someone who is not paired;
- a secret or a piece of personal data in this repository.

## Reporting

Please report it privately, not in a public issue: through GitHub's **Report a vulnerability**
button on this repository's Security tab, or by email to enys.mones@gmail.com.

Say what you found, how to make it happen, and which version (Settings → Version in the app, or the
`version` in `pyproject.toml` for a checkout). It is a personal project, so there is no promised response time, but a report
is read and a confirmed problem is fixed before anything else.

## Supported versions

Only the latest release.
